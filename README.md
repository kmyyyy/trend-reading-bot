# trend-reading-script
This tool works purely on technical analysis. Its suggestions may be inaccurate and should not be considered financial advice.
A simple script that reads EMA and SMA values and uses them to determine the trend and return a suggested action: BUY, SELL, or HOLD. 
The number of stocks and the EMA/SMA time periods can be customised.
In the near future, I am planning to add phone alerts for when a crossover happens.
